When updating a PR body via `gh api ... pulls/N -X PATCH -F body=...`, the new body MUST be: `<current content above marker> + <new auto-generated block>`. NOT just the auto-generated block.

**Why:** The user pastes Loom recording links, screenshots, and notes ABOVE the `<!-- auto-generated by claude -->` marker in PR bodies. Wholesale-PATCHing the body wipes all of it. CLAUDE.md says exactly this ("Preserve any user content above the markers") but it's easy to forget when re-running PR updates across a stack.

**How to apply:**
1. `gh api repos/<owner>/<repo>/pulls/<N> --jq '.body'` to fetch current body
2. Extract everything above `<!-- auto-generated by claude -->`
3. Concatenate: `<preserved> + <new auto-generated block>`
4. PATCH with the combined body

**Recovery if you clobbered:** GitHub keeps body edit history. Fetch via the GraphQL `userContentEdits` field — see `gh api graphql -f query='{ repository(owner:"O", name:"R") { pullRequest(number: N) { userContentEdits(first: 20) { nodes { editedAt, editor { login }, diff } } } } }'`. The `diff` field has the full historical body.
