Utkarsh Kher + Alberto Martinez Slack thread (C0BL9NYRT0A, 2026-07-28, bumped 2026-08-17) flagged 4 "treasury" webhook endpoints as unauthenticated. Validated 2026-08-17 (drift session): **concern is VALID.**

Correction to ticket: endpoints live in **venture** (`angellist.com`, public app), NOT treasury — treasury isn't publicly reachable so webhooks land in venture and proxy to `TreasuryAPI`.

Locations (`venture/config/routes.rb`):
- `POST /plaid_api/webhook` (routes.rb:669) → `app/controllers/plaid_api/webhook_controller.rb`
- `POST /alloy` (routes.rb:1602) → `app/controllers/alloy_api/webhook_controller.rb`
- `POST /treasury-prime-webhook` + `-manco` (routes.rb:1605-1606) → `app/controllers/treasury_prime_api/webhook_controller.rb`

Findings: venture `ApplicationController` has NO `authenticate_user!` (public app). All 3 controllers only `skip_before_action :verify_authenticity_token` (CSRF, not auth). No HMAC/signature/secret/bearer anywhere.

Severity NOT uniform:
- **Plaid = sharpest**: `AUTOMATICALLY_VERIFIED` branch (webhook_controller.rb:26-29) calls `complete_microdeposit_verification!` directly off payload, no Plaid callback → forged webhook w/ known item_id bypasses bank-acct ownership verification.
- **Alloy = direct**: forwards payload status straight to TreasuryAPI/EntityAPI (:31-35), forged KYC/txn status trusted.
- **Treasury Prime = partially self-protecting**: `treasury/app/controllers/api/treasury_primes_controller.rb:31` re-fetches by `event_id` from real TP API, doesn't trust payload. Lower blast radius.

Caveat: only saw app code — infra-level IP allowlist/WAF (if any) is a mitigation I couldn't verify. Flag to infra.

Fix (small, in-repo precedent): `venture/app/controllers/alto_ira_api/webhook_controller.rb:17,40` = `before_action :verify_alto_signature!` HMAC-SHA256 over raw body. Mirror per provider (Plaid JWT via `Plaid-Verification` header; TP + Alloy HMAC). NO new service needed — Kevin's BANK-960 "wait for generalized webhook service" defer is why it stalled 3wk; that service isn't shipped.
