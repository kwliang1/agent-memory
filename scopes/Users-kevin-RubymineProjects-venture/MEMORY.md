## Git workflow
- Use Graphite (`gt`) for all git operations: `gt modify -c` to commit, `gt submit` to push
- Add `--no-verify` when pre-commit hooks fail on pre-existing issues
- `gh pr edit` fails with a Projects Classic deprecation error; use `gh api` instead:
  `gh api repos/angellist/venture/pulls/NUMBER -X PATCH -f body="..." --jq '.html_url'`
- When PATCHing a PR body: fetch current body first, preserve everything above the `<!-- auto-generated by claude -->` marker (Looms / screenshots live there). See `feedback_pr_body_markers.md`.
