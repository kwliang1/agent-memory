When updating PR descriptions, ALWAYS fetch the current PR body first and preserve any user-added content (Loom links, screenshots, notes) that exists above the `<!-- auto-generated by claude -->` marker. Only replace content between the markers.

**Why:** User added a Loom link above the markers and it was accidentally removed during a PR body update.

**How to apply:** Before every `gh api ... --method PATCH --field body=`, fetch the current body, extract everything above `<!-- auto-generated by claude -->`, and prepend it to the new body.
